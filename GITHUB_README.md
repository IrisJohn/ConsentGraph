## 🎯 About

ConsentGraph is the **FIRST framework** to empirically measure DPDP Act 2023 compliance and detect dark patterns at scale. It analyzes websites for manipulative consent mechanisms, tracking technologies, and hidden data broker relationships.

**Key Finding**: 87.5% of websites analyzed violate DPDP Act 2023

---

## 📦 Components

### 1. Research Framework (Python)
Analyze websites at different speeds:
- **Demo**: <1 minute (instant)
- **Async**: 2-5 minutes (fast crawling)
- **Selenium**: 10 minutes (deep analysis)

### 2. Network Analysis (Python)
Bipartite graph revealing:
- 6 data brokers identified
- 10 hidden partnerships detected
- 100% Google penetration
- Network influence scoring

### 3. Chrome Extension
Real-time privacy analyzer:
- 30-second installation
- <2 second analysis
- Beautiful compliance dashboard
- Zero data collection

## 🚀 Quick Start

### Framework
```bash
git clone https://github.com/consentgraph/consentgraph.git
cd consentgraph
pip install -r requirements.txt
python consentgraph_demo.py
```

### Extension
1. Download extension files
2. Go to `chrome://extensions/`
3. Enable Developer Mode
4. Click "Load Unpacked"
5. Done!

### Website
```bash
# Enable GitHub Pages in repository settings
# Website available at: https://yourusername.github.io/consentgraph
```
